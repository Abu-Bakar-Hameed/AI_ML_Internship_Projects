# AI & ML Internship Projects

A collection of AI/ML projects covering data exploration, regression, classification, time-series prediction, and chatbots.

## Tasks Overview
1. **Iris Dataset Exploration:** Visualize relationships and distributions of iris features using pandas, seaborn, and matplotlib. Key insights: feature correlations and outliers.
2. **Stock Price Prediction:** Predict next-day closing prices using Linear Regression/Random Forest on Yahoo Finance data. Libraries: yfinance, scikit-learn.
3. **Heart Disease Prediction:** Classify heart disease risk using Logistic Regression/Decision Tree. Key features: cholesterol, age. Metrics: Accuracy, ROC-AUC.
4. **General Health Chatbot:** Query-based chatbot using GPT-3.5/Mistral-7B-Instruct with prompt engineering and safety filters.
5. **Mental Health Chatbot:** Fine-tuned DistilGPT2/GPT-Neo for empathetic responses. Dataset: EmpatheticDialogues. Interface: CLI or Streamlit.
6. **House Price Prediction:** Predict prices with regression models (Linear/Gradient Boosting). Key features: size, bedrooms, location. Evaluation: MAE, RMSE.
